# Bookmarks Manager

A lightweight, browser-based bookmarks manager for importing, organizing, and exporting Netscape-format `bookmarks.html` files.

## Features

* 📥 **Import bookmarks** — Load an existing `bookmarks.html` export.
* 📁 **Organize folders** — Create, rename, delete, expand, and rearrange folders.
* 🔖 **Manage bookmarks** — Add, edit, rename, and delete bookmarks.
* 🖱️ **Drag & drop** — Easily reorganize bookmarks and folders within the tree.
* 📤 **Export bookmarks** — Export the complete bookmark tree back to a standard `bookmarks.html` file.
* 📤➕ **Export a selection** — Add individual folders or bookmarks to a staging area and export only the selected items.
* ⚡ **No installation required** — Runs entirely in the browser using HTML, CSS, and JavaScript.
* 🌙 **Light/dark mode** — Automatically follows the system color scheme, with support for explicit themes.
* 📱 **Responsive UI** — Works on desktop and smaller screens.

## Why?

Browser bookmark managers can make it inconvenient to export only a specific folder or a handful of bookmarks. This tool provides a simple **Export a selection** workflow.

## Usage

1. Open the HTML file in a browser.
2. Import your existing `bookmarks.html` file.
3. Organize your bookmarks using drag & drop or the available actions.
4. Use **📤➕** beside any folder or bookmark to add it to the export staging area.
5. Click **Export selection** to create a smaller bookmarks file, or **Export bookmarks.html** to export everything.

No server, database, or external backend is required.
